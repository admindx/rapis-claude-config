# MQ会計 詳細リファレンス

## 基本変数・公式

| 変数 | 名称 | 定義 |
|------|------|------|
| P | Price（売価） | 製品・サービス1単位あたりの販売価格 |
| V | Variable Cost（変動費） | 原材料費、外注加工費、仕入原価等 |
| M | Marginal Profit（限界利益） | M = P - V |
| Q | Quantity（数量） | 販売数量 |
| F | Fixed Cost（固定費） | 人件費、家賃、減価償却費等 |
| G | Gain（経常利益） | G = MQ - F |

```
M = P - V
MQ = M × Q
G = MQ - F  ／  G = PQ - VQ - F
```

## 戦略変数の優先順位（利益改善効果順）

1. **P↑（売価を上げる）** - 値上げは全額Mに直結
2. **V↓（変動費を下げる）** - 下げた分だけMが増える
3. **Q↑（数量を増やす）** - Mが小さいと効果薄
4. **F↓（固定費を下げる）** - Gに直接効く
5. **MQ構成を変える** - M率の高い商品比率を上げる

## 重要指標

| 指標 | 計算式 | 意味 |
|------|--------|------|
| M率 | M ÷ P × 100 | 収益力の高さ（高いほど良い） |
| MQ | M × Q | 固定費を回収する原資 |
| 損益分岐点Q | F ÷ M | 利益ゼロになる販売数量 |
| 損益分岐点売上 | F ÷ M率 | 利益ゼロになる売上高 |
| 安全余裕率 | (実際売上 - 損益分岐点売上) ÷ 実際売上 × 100 | 赤字までの余裕度 |

## 思考原則

- **MQ脳で考える**: 売上（PQ）ではなくMQ（限界利益総額）で判断
- **売上至上主義を排す**: PQが大きくてもMが小さければ利益は出ない
- **値引きの本当のコスト**: Pを下げるとMが直接減る。M率が低い商品の値引きは致命的
- **固変分解が基本**: コストは必ず変動費（V）と固定費（F）に分解して分析
- **商品別・顧客別にMを把握**: 全体平均ではなく個別のM・M率で意思決定
- **MQ>0なら撤退しない**: Gがマイナスでも、MQがプラスならFの回収に貢献している

## 社内共通用語

| 用語 | 意味 |
|------|------|
| M率が高い/低い | 収益性が高い/低い |
| MQで回す | 限界利益総額で固定費を回収する |
| Pで勝負する | 値上げ・高価格戦略を取る |
| Vを叩く | 変動費（原価）を下げる |
| Fが重い | 固定費負担が大きい |
| 損益分岐を割る | 赤字に転落する |
| MQ > F | 黒字状態 |
| MQ < F | 赤字状態 |
| 戦略変数を動かす | P, V, Q, F のいずれかを変化させて利益改善を図る |
