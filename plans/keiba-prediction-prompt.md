# 競馬予想プロンプト（統計アナリスト版）

## 概要

このプロンプトは、競馬レースを「期待値最大化」の観点から分析するための統計アナリスト用テンプレートです。本命だけでなく穴馬も同時に拾い、市場の歪みを見抜くことを目的としています。

---

## プロンプト本体

```
あなたは競馬の統計アナリストです。
以下の条件でレースを分析し、期待値の高い買い目を出してください。

【目的】
・勝率ではなく「期待値最大化」
・本命＋穴を同時に拾う

【分析対象】
・出走馬一覧
・騎手データ
・近走成績（直近5走）
・血統（父・母父）
・馬場状態（天気・含水率）
・コース特性（京都3200mなど）

【分析手順】
① 市場評価分析
・単勝オッズから暗黙の勝率を算出（暗黙勝率 = 0.8 ÷ 単勝オッズ）
・人気と実力の乖離を抽出

② パフォーマンス分析
・近走の距離適性
・上がり3F・位置取り
・長距離実績

③ 騎手補正
・該当コースの複勝率
・長距離G1実績

④ 血統分析
・父系の距離適性（例：キタサンブラック＝長距離）
・重馬場適性

⑤ 展開シナリオ（3パターン）
・スロー（前残り）
・平均（実力通り）
・ハイ（差し決着）

⑥ 穴馬抽出ロジック
以下を満たす馬を抽出：
・人気10番手以下
・長距離ローテ経験あり
・血統的に距離適性あり
・近走で上がり良い or 着順以上の内容

⑦ スコアリング
・能力（40%）
・適性（30%）
・騎手（15%）
・展開（15%）

⑧ 最終出力
・推定勝率（%）
・期待値（オッズ×確率）
・買い目（3連複・3連単）

【出力形式】
・本命（勝率）
・対抗
・穴（必ず1頭以上）
・3連複（1点〜5点）
・3連単（1点〜5点）

【制約】
・人気順に引っ張られない
・必ず「市場の歪み」を1つ指摘する
・なぜその馬が過小評価されているかを説明する
```

## 予想のプロとしての補足解説

### ❶ 期待値の基本式
```
期待値（EV） = 単勝オッズ × 推定勝率
EV > 1.0 → 買い妙味あり
EV < 1.0 → 見送り
```
JRAの単勝控除率は約20%のため、暗黙勝率は `0.8 ÷ オッズ` で近似できます。
（例：単勝5.0倍なら暗黙勝率16%、自分の推定が25%ならEV=1.25で買い）

### ❷ 市場評価分析（① の深掘り）
- **人気馬の罠**：1〜3番人気は控除率の影響を受けやすく、EVが1.0を超えにくい
- **オイシイ価格帯**：単勝7〜30倍ゾーンに「市場の歪み」が出やすい
- **過剰人気の見抜き方**：前走勝ち＋同コース実績＋有名騎手 → 三拍子揃うと過剰人気しやすい

### ❸ パフォーマンス分析（② の深掘り）
| 指標 | 見るポイント |
|------|------|
| 上がり3F | 33秒台は瞬発力◎／35秒台は持続力型 |
| 位置取り | 4角での通過順とラップ消耗度 |
| レースレベル | 同じ着順でもメンバー構成で価値が変わる |
| 距離経験 | 長距離は「経験値」が能力以上にモノを言う |

### ❹ 騎手補正（③ の深掘り）
- 該当コースの複勝率 **20%以上**で +補正
- 長距離G1（菊花賞・天皇賞春・有馬記念）勝ち鞍あり → 長距離戦の信頼度UP
- 騎手×厩舎×馬主の「鉄板コンビ」は要マーク

### ❺ 血統分析（④ の深掘り）
| 系統 | 適性 |
|------|------|
| キタサンブラック / ドゥラメンテ | 長距離・スタミナ型 |
| ディープインパクト系 | 中距離・瞬発力型 |
| ハーツクライ系 | 重馬場・タフな展開◎ |
| ロードカナロア系 | 短〜マイル・スピード型 |

母父（BMS）は隠し味。ステイゴールド・トニービン系は長距離で覚醒しやすい傾向。

### ❻ 馬場状態と含水率
- **含水率10%以下**：高速馬場 → 前残り・先行有利
- **含水率15%前後**：標準
- **含水率20%超 or 重馬場**：パワー型・欧州血統が浮上

### ❼ 展開シナリオ別の狙い目
| ペース | 有利脚質 | 狙う馬の特徴 |
|--------|----------|------|
| スロー | 逃げ・先行 | 折り合い○、上がり勝負に対応可 |
| 平均 | 差し・先行 | 総合力上位馬 |
| ハイ | 差し・追込 | 末脚特化型・上がり最速経験あり |

### ❽ 穴馬抽出の実践ポイント（⑥ の深掘り）
**「過小評価される馬」の典型パターン**
1. 前走大敗（ただし展開不利・距離不適だった）
2. 騎手乗替で人気を落とした（実は新騎手の方がコース得意）
3. 長距離初挑戦だが、母父にステイヤー血統
4. 休み明けで人気薄 → 一回叩き or 滞在競馬で良化
5. 馬体重大幅増減で嫌われた → 実は成長分

### ❾ 買い目構築の原則
- **3連複**：本命1頭軸＋相手4〜5頭（5〜10点）でフォーメーション
- **3連単**：1着固定が読める時のみ。2-3着は流す
- **資金配分**：期待値の高い買い目に厚く、保険は薄く

### ❿ 市場の歪みチェックリスト（必ず1つ指摘）
- [ ] 過剰人気馬（実力以上にオッズが集中）
- [ ] 過小評価馬（前走の見えない不利／距離適性／血統的優位）
- [ ] 騎手評価のズレ（騎手×コース相性が反映されていない）
- [ ] 馬場読みのズレ（高速馬場想定だが含水率高め等）

## 注意事項

- 競馬は確率事象であり、本プロンプトは**期待値ベースの判断補助**を目的とします
- 投資は自己責任で。資金管理（1点あたり総資金の3〜5%以内）を徹底してください
- 出走除外・騎手変更・馬場急変などの直前情報は別途反映が必要です
